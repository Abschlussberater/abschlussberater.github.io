# Abschlussberatung Sek I

Beratungs-App zu den Schulabschlüssen der Sekundarstufe I in Brandenburg (Gesamtschule, Oberschule, Gymnasium):
geführte Beratung, Abschlussrechner, Prüfungsnotenrechner, Wege nach Klasse 10, Glossar, FAQ und Rechtsquellen.

**Website:** https://abschlussberater.github.io/

Die App ist eine einzelne HTML-Datei. Sie läuft komplett im Browser, setzt keine Cookies, speichert nichts und lädt nichts nach.
Orientierung, keine Entscheidung – verbindlich entscheidet die Klassenkonferenz.
